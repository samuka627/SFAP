# SFAP
SFAP is a simple ADB panel that is used by your own phone or by a device such as another phone or a computer through a terminal and ADB.

# How to use it

1. Have a terminal emulator (we recommend Termux).

2. Install Git and Clang (in Termux type "pkg install git clang").

3. In Termux, clone the GitHub repository of the installer for the version you want and compile it.

4. Run the compiled file, accept, and wait.
